# Input data guide

None of the large input datasets are stored in this repository. Download them
from the sources below, load them into the ArcGIS Pro project and geodatabase
set in `config.yaml` (`paths.aprx`, `paths.gdb`), and name the layers as in
`gis.layers`.

> Check every link and licence before use. Sites and dataset versions change.

## Spatial inputs

| Layer (`gis.layers`) | Dataset | Source | Notes |
|---|---|---|---|
| `vri` → `VRI_{year}_AOI` | **VRI – Forest Vegetation Composite Rank 1 Layer (R1)**, one per landscape year (2022 in the paper) | BC Data Catalogue: https://catalogue.data.gov.bc.ca/ (search "VRI Forest Vegetation Composite Polygons"). Historical years are on the BC Ministry of Forests VRI data page. | Open Government Licence – British Columbia. Clip to the AOI. Must contain `POLYGON_ID`, `SPECIES_CD_1..4`, `SPECIES_PCT_1..4`, `PROJ_HEIGHT_1`, `PROJ_AGE_1`, `SITE_INDEX`, `QUAD_DIAM_125`, `VRI_LIVE_STEMS_PER_HA`, `VRI_DEAD_STEMS_PER_HA`, `BCLCS_LEVEL_4`, `POLYGON_AREA`. Data dictionary: VRI "VegComp Poly Rank 1 Data Dictionary". |
| `fuel_types` → `VRI_Wildfire_Fire_Fuel_Types_AOI_{year}` | **BCWS Fire Fuel Types (FBP)** | BC Data Catalogue (BC Wildfire Service, "Fire Fuel Types"). | Field `FUEL_TYPE_CD`. |
| `dem` → `DEM` | Digital elevation model | (https://catalogue.data.gov.bc.ca/dataset/digital-elevation-model-for-british-columbia-cded-1-250-000) | Projected to BC Albers (EPSG:3005) and resampled to `gis.resolution_m` by step 6.
| `aoi` → `AOI` | Study-area boundary | Defined by the user | |
| `treatments` → `WalkPoly_all_years_Dissolve` | Treatment (burned-area) polygons | **Not distributed.** Community data. | Supply your own polygons of treated areas, dissolved to one layer. Only the geometry is used: step 0 computes the % of each VRI polygon that was treated. |

## Files shipped in this repository

| File | Content |
|---|---|
| `data/supporting/fuel_type_conversion.csv` | Canadian FBP fuel type → US standard fuel model (`code_usa`), treated fuel model for the low and high treated-fuel assumptions (`treated_low`, `treated_high`), and the FCCS fuelbed used for FOFEM. It merges the two working tables `Dictionary_fuel_type_CAN_and_USA_{low,high}.xlsx`, which differed only in `treated_*`. |

## Not shared

- Treatment polygons and every table derived from them
  (`Treatment_intersection_{year}.xlsx`, which lists the treated VRI polygons).
- Intermediate files (FVS databases, FOFEM batch files, landscape rasters):
  these are regenerated by the pipeline.
